# 项目计划书唯一维护入口

本仓库的唯一正式项目计划书为：

```text
AI_API_Autotest_Framework_Project_Plan_Latest.md
```

该文件位于仓库根目录。

为避免同一阶段出现多份“Latest”并逐渐产生状态冲突，`docs/00_项目计划书_Latest.md` 不再保存第二份计划正文。后续每个阶段只在根目录计划书的**上一版内容上原位更新**：设计讨论完成后更新一次，实施过程中出现真实问题时继续更新同一文件，阶段验收后再更新其完成状态。

历史设计/实施细节继续保存在：

```text
docs/superpowers/specs/
docs/superpowers/plans/
docs/evidence/
```

这些文件用于保存阶段证据和实施过程，不替代根目录主计划书。
